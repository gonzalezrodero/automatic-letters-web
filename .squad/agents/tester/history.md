## Learnings

### 2026-11-21 — Onboarding

#### Architecture

- Two surfaces. The repo-root static site is the landing and legal pages. `admin/` is the React/Vite portal, served with base `/admin/`. Login in a production build is Cognito only.
- Unit tests are colocated: 14 files matching `admin/src/**/*.test.ts`. There is no `vitest.config.ts` and no `test` key in `admin/vite.config.ts`. `npm test` is `vitest run` (one shot, no watch). Vitest 5.0.5 therefore uses that Vite config and its own defaults (Node environment; `*.test.ts` / `*.spec.ts`). `admin/e2e/smoke.pw.ts` is outside that pattern, so Vitest does not collect the smoke suite.
- `npm run build` is `tsc -b && vite build`. `admin/tsconfig.app.json` `include`s all of `src`, so the unit tests are typechecked with the app. `types` is only `["node"]`. Tests import `describe`, `it`, and `expect` from `vitest` (no globals). `admin/tsconfig.node.json` typechecks `vite.config.ts` only. Engines and `admin/.nvmrc` are Node 24.
- Playwright is `admin/playwright.config.ts` plus the single file `admin/e2e/smoke.pw.ts` (`testMatch: **/*.pw.ts`). Chromium only, `workers: 1`, `fullyParallel: false`, `retries: 0`, `timeout: 30_000`, `expect.timeout: 10_000`, `forbidOnly` when `CI` is set. Trace `retain-on-failure`, screenshot `only-on-failure`, video off. `baseURL` is `http://127.0.0.1:4173`.
- `webServer` starts two processes. `npm run preview` on port 4173 (ready when `/admin/` responds) and `python3 -m http.server 4174 --bind 127.0.0.1` with cwd at the repo root. `reuseExistingServer` is on outside CI. Preview does not rebuild; the suite runs the bundle from `npm run build`.
- Production mode in `admin/vite.config.ts` throws unless `VITE_API_BASE`, `VITE_COGNITO_DOMAIN`, and `VITE_COGNITO_CLIENT_ID` are set. CI and the README use the dummy hosts `https://api.example.invalid`, `auth.example.invalid`, and `ci-client`. The preview webServer sets those same three. `.env.development` is for `npm run dev` only.
- Smoke mocks the API in the page. `API_ORIGIN` is `https://api.example.invalid`. `installApi` registers a `**/*` route that `continue`s `127.0.0.1` / `localhost` and aborts every other URL (recorded in `problems.blocked`), then a later route for `${API_ORIGIN}/**`. Playwright gives the last registered route priority. Logged-out `GET /me` is an empty 200 so the portal stays on login without `console.error`. The admin session returns email `ada@example.com`, name `Ada`, groups `['admin']`, plus JSON for one invented tenant, dashboard, conversation, document, and empty unanswered lists. `OPTIONS` is 204. Any other method or path is 500 `{ unexpected }`. The suite does not call Cognito.
- `watch` collects page errors, `console` type `error`, responses with status >= 400, and `requestfailed` (it skips `ERR_BLOCKED_BY_CLIENT` and `ABORTED`). `assertClean` expects `pageErrors`, `consoleErrors`, `httpFailures`, and `blocked` to be `[]`.
- Axe is `@axe-core/playwright` 4.14.0. `expectNoSeriousAxeViolations` waits for `document.fonts.ready`, runs `new AxeBuilder({ page }).analyze()`, and keeps violations whose `impact` is `serious` or `critical`. The assertion message lists `id`, impact, `help`, and node targets. Moderate, minor, and incomplete results do not fail the run. The comment names incomplete color-contrast on single-character chart labels as an example of a non-failure.
- No migrations. No `.sql`, Prisma, Drizzle, Alembic, or Flyway files, and no migration mentions in project markdown, workflows, or TypeScript.

#### Conventions

- Extend a test that already covers the behavior. Keep tests next to the module. Expected UI strings are the Spanish copy the product shows. Test titles stay English. `AGENTS.md` requires `npm test`, `npm run build`, and `npm run e2e` in `admin/` before finishing, and both `admin/src/theme.contrast.test.ts` and the smoke tests must pass.
- Smoke locators are roles and accessible names (`getByRole('heading')`, `button`, `navigation`, `link`, `alert`, `textbox`). Layout checks use the selectors the page already has: `.hero-copy`, `#ejemplo`, `#sirve-titulo`, `.login-story`, `.login-aside`, `.login-chat`, `.login-panel`, `main#contenido`.
- Auth and HTTP tests pass a fake `fetch`, set `credentials: 'include'`, and spy on `console.error`. A failure body, token field, or provider `error_description` must stay out of the thrown message and out of the spy. `console.error` is called as `('API error', status)` only. Spies are `mockRestore`d.
- `theme.contrast.test.ts` reads `site.css` and `admin/src/index.css` from disk (it does not render). Pinned hex values `#fffbeb`, `#0f766e`, `#f97316`, `#c2410c`, `#1c1917` must appear in both files. Text pairs use the WCAG luminance ratio and must be >= 4.5. White and teal on `#f97316` must be < 3. Danger `#9f2d2d` must differ from orange and ember, with contrast against orange >= 1.4.
- UI bar from `AGENTS.md`: widths 320, 768, and 1280; horizontal overflow is `scrollWidth - clientWidth <= 0`; the login page must not scroll at short heights (document and those login panels); the landing must not leave a large gap under the hero. The smoke gap ceiling is 120px.
- CI workflow `.github/workflows/admin-portal.yml` runs `npm ci`, `npm test`, `npm run build` (dummy env), `npx playwright install --with-deps chromium`, then `npm run e2e`, all with working directory `admin`. The job name is `build`. Leave that name alone. Lead reviews test changes.
- Fixtures are invented (`example-tenant`, `api.example.invalid`, `ada@example.com`). Do not copy live hosts, client ids, or tokens out of a test into notes or logs.

#### Gotchas

- `npm run e2e` fails if `dist` was not built with the three dummy variables. Preview re-reads them; it does not compile.
- The landing gap test depends on `python3` on port 4174. CI is `ubuntu-latest`. This workstation is Windows, where `python3` may be absent even when `py` or `python` exists. The axe landing test does not use that server; it fulfills files on the preview origin.
- A 401 from the mocked API during smoke is an `httpFailures` entry and fails `assertClean`. Logged-out smoke stays clean only because `GET /me` is an empty 200. Cover 401 in `session.test.ts`, not by changing the smoke `/me` stub to 401.
- `installApi` / `installLanding` record the URL in `blocked` and then abort it. `watch` ignores the resulting `ABORTED` failure, so the failure shows up as `blocked`, not as `httpFailures`.
- Login no-scroll coverage is the five `loginViewports` plus 390×844. Widths 320 and 768 only assert overflow. Authenticated pages use 1280×800. The landing gap uses 1440×900 and 390×844. A change aimed at 320/768/1280 still has to satisfy those existing sizes.
- `expectNoDocumentScroll` and `expectNoPanelScroll` fail when extra pixels are greater than 0. Hidden login panels (`display: none`) contribute 0.
- Public `http` privacy URLs are rejected in the settings smoke test and in `safeNavigationUrl`. Loopback `http` is allowed in the unit test only.
- `tsc -b` typechecks every file under `admin/src`, including tests. A type error in a test fails `npm run build`.
- Outside CI, a process already bound to 4173 or 4174 is reused. A stale preview serves a stale bundle.
- No coverage dependency is installed. Adding one would be a new dependency, which the minimal-tests decision argues against unless the task asks for it.
